  4. 04Agacharse en el auto y menú del vehículo

    Se puede mantener Círculo para que Jason se agache dentro del auto y así evitar que la policía lo vea. También hay un menú de vehículo para controlar las ventanillas y otras funciones.

    1. Mantener Círculo para agacharse dentro del auto.
    2. Mantener abajo en la cruceta y mover el stick derecho hacia arriba para abrir el menú del vehículo (en PS5).
    Ver la guía completa →

  5. 05100 consejos para empezar

    Guía con consejos clave: el Capítulo 1 resetea tu plata, conviene guardar $5.000 en Family Savings y comprar armas y ropa antes; incluye un garage Growler gratis con código.

    1. Antes de que termine el Capítulo 1, poner $5.000 en Family Savings.
    2. Comprar armas y ropa antes del reinicio.
    3. Usar el código 92665 para obtener el garage Growler gratis, cerca de Auntie's Place.
