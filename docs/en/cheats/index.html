GTA 6 cheats: every code

All 61 GTA 6 cheats, what each one does and what you have to do to unlock it. 17 have a code confirmed by two different guides.

How to enter them

  1. Finish the story: only then does the cheats section show up in the Progress menu.
  2. Meet each cheat's requirement. Once you do, the game shows you the code in Progress.
  3. Pull out your phone (up on the d-pad), hold L1 + R1 on PS5 or LB + RB on Xbox and dial the sequence.

Before using them: while a cheat is active you don't earn trophies or achievements and the game doesn't save. Save first.

Codes are the same on PS5 and Xbox. Arrows are d-pad directions.
