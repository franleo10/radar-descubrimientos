Truques de GTA 6: todos os códigos

Os 61 truques de GTA 6, o que cada um faz e o que é preciso fazer para desbloqueá-lo. 17 têm o código confirmado por dois guias diferentes.

Como ativar

  1. Termine a história: só então aparece a seção de truques no menu Progresso.
  2. Cumpra o requisito de cada truque. Quando você cumpre, o jogo mostra o código em Progresso.
  3. Pegue o celular (seta para cima no direcional), segure L1 + R1 no PS5 ou LB + RB no Xbox e digite a sequência.

Antes de usar: enquanto houver um truque ativo você não ganha troféus nem conquistas e o jogo não salva. Salve antes.

Os códigos são iguais no PS5 e no Xbox. As setas são do direcional.
